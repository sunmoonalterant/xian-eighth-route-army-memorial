# D11.5 全站内容缺口审计

审计日期：2026-09-04。审计依据为当前 Vue 数据模块、后端路由/模型、`crawler/node/output/reviewed/`、现有 MySQL **只读统计**与本地化图片清单；未把课程演示内容或常识补成史实。

## 统计口径

- MySQL 统计：`museum=1`；`relic=10`（`status=1` 为 9、`status=0` 为 1）；`exhibition=4`（公开 2、下线 2）；`article=6`（公开 5、下线 1）；`person=0`、`history_event=0`、`courtyard=0`。
- 静态官方回退：馆情 1、文物 9、展览原始记录 3（经语义去重后供展示）、新闻 5、参观资料 1、泛旧址保护资料 1；人物与时间线均为空数组。
- `status` 只表示前台上线状态；`verified` / `reviewStatus` 表示资料人工核验状态。现存官网采集资料仍多为 `verified: false`、`reviewStatus: pending`，不等同于最终史料审定。

## 当前资料边界

- 当前无可发布的人物、历史事件或具体院落记录；它们均不得因页面空白而导入数据库或恢复游客端展示。
- `officialCourtyards.js` 的一条旧址保护资料不支持任何具体院落用途或图片归属。
- MySQL 中额外的下线文物、展览和新闻不计为游客端正式公开内容；其状态和来源需由管理员人工复核。
- 图片本地化报告只证明曾成功保存远程封面，不证明照片必然对应具体历史人物、事件或院落。
