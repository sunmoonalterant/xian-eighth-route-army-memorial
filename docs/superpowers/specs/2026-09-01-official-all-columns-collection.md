# 官网全栏目公开资料采集与前台整理设计

## 目标

对八路军西安办事处纪念馆官网的十个公开栏目进行低频、串行的结构发现和资料采集，输出可复查的原始响应、待审核 JSON 与前端静态数据。资料只来自无需登录的官网页面或其页面源码明确调用的公开接口；每条导出资料均保持 `verified: false` 和 `reviewStatus: "pending"`。

## 范围与限制

栏目为：首页、展馆介绍、文博资讯、陈列展览、公众教育、馆藏文物、学术研究、旧址保护、参观服务、财务公开。采集器先保存每个栏目页面，再从页面源码中提取已出现的 API 方法、参数和 Vue 数据字段。只有这一证据充分时才调用列表接口；详情接口必须同样在页面源码中存在。

所有请求单线程执行，相邻请求延迟 1--3 秒。遇到 401、403、405、429、登录、验证码、付费提示、接口格式异常或连续网络失败时，记录原因并停止该接口，不尝试绕过或替代接口。不会使用代理池、浏览器自动化、身份凭据、批量下载图片或站外补充资料。

“全部”表示遍历可公开访问且由列表接口明确报告的全部分页与已列出的详情，直至该栏目声明的总数收集完毕；在本站点拒绝访问、接口失效或本次会话的运行时间不足时，已收集部分必须明确标为不完整，不能用推断资料填充缺失项。

## 数据与前台映射

原始页面与 API 响应写入 `crawler/node/output/debug/`，保留 URL、请求时间、HTTP 状态和响应体。采集结果写入 `crawler/node/output/raw/`，并以统一来源字段、采集时间和审核状态标准化。审核导出写入 `crawler/node/output/reviewed/`，不会覆盖原始文件。

前端永远只导入 `frontend/src/data/official*.js` 静态模块。展馆介绍映射馆情；文博资讯映射新闻；陈列展览映射展览；馆藏文物映射文物；旧址保护映射数字纪念馆院落；参观服务映射参观页。公众教育、学术研究和财务公开若前端没有对应页面，先导出审核 JSON 和来源链接，不虚构新的前台功能。历史事件和人物仅在官网公开资料含有明确条目、日期/身份字段时才替换；否则显示“资料待补充核实”。

导出的 HTML 去掉 `script`、`style`、`iframe` 和内联事件属性；前端仍需采用最小白名单净化。官网图片只引用原始 URL；图片加载失败使用现有占位图。正文、缩略图和标题必须保留来源 URL，且页面显示“官网公开资料，待审核”。

## 实施、验证与可追溯性

实现一个配置化 Node 采集脚本：页面描述、API 模板、分页器、请求延迟、响应保存和保守结构化映射各自独立。脚本必须支持单栏目运行和全栏目运行，默认不并行。每次写入前按来源 URL 与栏目条目 ID 去重，并产生栏目级统计（发现、成功、跳过、失败、未映射到前端）。

用离线固定响应测试接口发现、分页停止、拒绝状态停止、HTML 清理、字段保守映射和导出状态；再进行一次实际低频运行。最后执行前端全部测试和生产构建。报告必须区分：官网页面访问成功、API 成功、可映射的前台资料、无法确认的占位资料与被拒绝的接口。
