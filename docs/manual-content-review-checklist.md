# D11.5 人工内容审核清单

本清单用于决定候选资料是否可进入下一阶段的“审核通过资料入库”。勾选本清单不等于自动上线；只有人工确认后，才可另行决定数据库、API 与游客端展示。

## 人物（8 条候选）

- [ ] 在纪念馆官网可访问的原始资料、官方发布渠道或 B 级权威资料中，逐一确认周恩来、朱德、刘少奇、彭德怀、叶剑英、邓小平、林伯渠、董必武与办事处的“曾多次留驻并指导工作”关系。
- [ ] 不把来源未提供的出生年、逝世年、别名、职务、生平扩写为候选事实。
- [ ] 如补充人物照片，逐图确认历史人物身份、图片原始发布页、发布者与版权/使用边界。
- [ ] 没有可确认图片时，保留 `image=null` 和中性剪影，不使用生成式头像、演员照片或相似年代照片。

## 历史事件（12 条候选）

- [ ] 复核“1936年至1946年”是阶段范围，不能拆成某一具体机构的设立日期。
- [ ] 复核1937年8月设立与1946年9月撤销，仅保留月精度，不补具体日。
- [ ] 复核1959年纪念馆成立和1988年旧址公布信息的原始出处。
- [ ] 复核1997、2006、2015、2020、2022、2023、2025各项称号/入选信息的发布机构、年份和完整名称。
- [ ] 任何候选事件若有不同可靠来源日期，改为 `reviewStatus: conflict` 并登记冲突来源，不自行裁决。
- [ ] 没有一一对应的事件图片时，不本地化或挂接通用建筑图片。

## 七贤庄院落（4 条候选）

- [ ] 复核一号院“主要办公地点”来源记录（`sourceApiId=14`）能否在官方页面或官方接口中重新定位。
- [ ] 复核三号院统战科旧址、四号院采办委员会暨经理科旧址、七号院联合招生委员会旧址的逐项原文出处。
- [ ] 确认院落名称与用途不是仅由编号、文件名或平面图位置推断。
- [ ] 如出现院落图片，确认图片直接关联该院落；没有图注/上下文时标记 `uncertain`，不下载本地化。
- [ ] 前端热点 `positionX` / `positionY` 仅是 UI 布局数据，不可作为地理测绘或历史资料审核项。

## 馆情、文物、展览与新闻

- [ ] 核对馆情正文与官网当前动态内容的关系；确认可作为馆情封面的图片来源和对应性。
- [ ] 对 9 条公开文物逐条确认稳定 ID、名称、分类、年代、详情来源和封面对应性；缺字段保留 null。
- [ ] 对展览按稳定详情页身份和正文语义审核；确认 `sourceApiId=8` / `13` 的语义重复处置，禁止按图库图重复入库。
- [ ] 对 5 条新闻逐条确认官方文章参数、发布日期、分类与封面对应性；不为增加数量批量补旧新闻。

## 参观服务

- [ ] 通过当前官方公告或明确官方渠道确认地址、开放时间、周一闭馆例外、预约方式、交通和讲解服务。
- [ ] 若多个官方页面不一致，记录 `conflictingSources`，在人工裁决前不改游客端服务信息。
- [ ] 不把课程项目预约时段模拟设置误写为纪念馆官方开放/预约规则。
