# D13 后台运营统计看板

D13 在 `/admin/dashboard` 展示数据总览，`/admin` 默认进入该路由，并沿用现有管理员 JWT 守卫与 Axios 401 处理。

数据只来自 D12 六个接口：overview、traffic-trend、page-ranking、reservations、reservation-trend、period-distribution。D13 不修改 PV/UV、动态路径 UV、预约状态或有效预约的统计口径，也不修改后端或数据库。

页面包含六张指标卡（总/今日 PV、总/今日 UV、预约总数、有效预约）、PV/UV 折线图、页面排行横柱图、预约状态环图、预约趋势折线图和时段分布柱图。顶部 7/14/30 天控制仅重新请求两类趋势接口；刷新按钮并行重载六个模块。

每个模块分别呈现 loading、empty、error 或 success，失败不会隐藏其他模块；全零预约状态、空排行和空时段均显示真实空状态，不注入演示数据。图表组件在卸载时移除 resize 监听并 dispose ECharts 实例；移动端卡片和图表单列，侧栏可横向滚动。
